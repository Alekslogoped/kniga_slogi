Читаем вместе

Сначала прочитайте слоги. Произносите согласный звук коротко, без добавления «э»: «м», затем плавно соединяйте с гласным — «ма».

На следующих разворотах — слова первой слоговой структуры: два открытых слога. Прочитайте каждый слог, затем всё слово слитно: МА-МА → МАМА. Нажимайте на слоги, чтобы выделять их по очереди. После чтения слова нажмите «Прочитал!» — в травке вырастет цветок. Прочитайте весь разворот, чтобы прилетела бабочка. Кнопка «Ещё раз» очищает цветы на странице.

Перелистывайте кнопками, клавишами ← → или движением пальца. В меню над кнопками можно выбрать любой разворот.
